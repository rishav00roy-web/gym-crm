# IQIron Gym CRM 🏋️

A lightweight, browser-based CRM built for independent gym owners. No backend, no database, no monthly fees — just open and use.

## Features
- 👥 Member management
- 📱 WhatsApp messaging integration
- ⏰ Membership expiry tracker
- 💾 Local storage based — data stays in your browser
- 🌐 Two versions — optimized for Chrome and Edge

## How to Use
1. Download either the Chrome or Edge version
2. Open in your browser
3. Start adding members — no setup needed

## Built With
- HTML
- CSS
- JavaScript

## Note
This project was built for a real gym owner and has been sold commercially. Shared here as an open source reference.
